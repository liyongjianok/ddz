# 任务 Backlog

## 1. Sprint 策略

按小的垂直切片开发。每个 Sprint 结束时，项目应保持可运行或至少可测试。

AI 辅助开发推荐：

- 每个 Sprint 1 到 3 天。
- 每个 Sprint 3 到 8 个强边界任务。

## 2. Milestone 0：项目脚手架

### T-0001 创建仓库结构

范围：

- 创建 `backend/`、`frontend/`、`deploy/`、`docs/`。
- 初始化 Go module。
- 初始化 Vite React TypeScript 前端。
- 添加 README。

验收：

- `go test ./...` 可运行。
- 前端安装/构建命令有文档。

### T-0002 后端配置和服务骨架

范围：

- 配置加载。
- HTTP server 骨架。
- health endpoint。

验收：

- `GET /healthz` 返回 OK。
- 配置可从环境变量读取。

## 3. Milestone 1：规则引擎

### T-1001 牌模型和牌堆

文档：

- [06-domain-model.md](./06-domain-model.md)
- [12-game-rules-engine.md](./12-game-rules-engine.md)

范围：

- 实现 `Card`、`Rank`、`Suit`。
- 解析牌编码。
- 生成标准牌堆。
- 使用可注入 RNG 洗牌。
- 发牌 17/17/17 和 3 张底牌。

验收：

- 牌堆 54 张唯一牌。
- 非法牌编码被拒绝。
- 发牌数量正确。

### T-1002 牌型识别

范围：

- 识别所有 MVP 牌型。
- 返回 type、primary rank、length、attachments。

验收：

- 单元测试覆盖所有合法和非法牌型。

### T-1003 出牌比较

范围：

- 实现 `CanBeat(candidate, previous)`。
- 支持炸弹和火箭。

验收：

- 同牌型高点数获胜。
- 炸弹压非炸弹。
- 火箭压所有牌。
- 非法比较被拒绝。

### T-1004 合法出牌生成

范围：

- 从手牌生成合法响应。
- 生成主动出牌候选。

验收：

- 可被提示和机器人复用。
- 测试覆盖常见手牌。

## 4. Milestone 2：游戏状态机

### T-2001 游戏初始化

范围：

- 创建游戏和玩家。
- 洗牌/发牌。
- 设置叫分起始座位。

验收：

- 初始状态满足不变量。

### T-2002 叫分状态

范围：

- 实现叫分校验。
- 选择地主。
- 处理全部不叫。

验收：

- 非法叫分被拒绝。
- 叫 3 立即结束叫分。
- 地主收到底牌。

### T-2003 出牌状态

范围：

- 实现出牌。
- 实现不出。
- 回合推进。
- 检测游戏结束。

验收：

- 非当前玩家不能出牌。
- 不能出不在手里的牌。
- 主动出牌不能不出。
- 手牌为空游戏结束。

### T-2004 结算

范围：

- 计算胜利方。
- 计算分数变化。
- 应用倍数。

验收：

- 地主胜/负分数正确。
- 农民胜/负分数正确。
- 返回倍数原因。

验收：

### T-3004 超时系统

范围：

- 回合截止时间。

验收：

- 超时进入同一命令队列。
- 玩家已操作后不触发重复超时动作。
