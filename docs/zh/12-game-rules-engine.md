# 游戏规则引擎

## 1. 目的

本文档定义后端规则引擎实现的斗地主规则。

规则引擎必须：

- 确定。
- 可单元测试。
- 独立于 HTTP、WebSocket 和数据库。
- 是玩法校验的唯一事实来源。

## 2. 牌堆

使用一副 54 张标准牌：

- 52 张花色牌。
- 小王。
- 大王。

牌编码：

```text
S3 H3 C3 D3 ... SA HA CA DA S2 H2 C2 D2 BJ RJ
```

点数顺序：

```text
3 < 4 < 5 < 6 < 7 < 8 < 9 < T < J < Q < K < A < 2 < BJ < RJ
```

花色不参与比较。

## 3. 发牌

三人玩法：

- 玩家 0：17 张。
- 玩家 1：17 张。
- 玩家 2：17 张。
- 底牌：3 张。

服务端洗牌和发牌。

## 4. 叫分规则

MVP 使用叫分：

- 合法分数：0、1、2、3。
- 0 表示不叫。
- 非 0 分数必须高于当前最高分。
- 叫 3 立即成为地主。
- 如果无人叫 3，则最高叫分者成为地主。
- 如果全部不叫，执行 all-pass 策略。

all-pass 策略：

1. 重新发牌一次。
2. 如果再次全部不叫，随机指定地主，叫分按 1。

地主确定后：

- 地主获得底牌。
- 地主先出。
- 叫分参与倍数。

## 5. 牌型

### 5.1 单张

一张牌。

```text
S3
```

### 5.2 对子

两张相同点数。

```text
S3 H3
```

大小王不能组成普通对子。

### 5.3 三张

三张相同点数。

```text
S3 H3 D3
```

### 5.4 三带一

三张相同点数加一张单牌。

```text
S3 H3 D3 S4
```

### 5.5 三带二

三张相同点数加一个对子。

```text
S3 H3 D3 S4 H4
```

### 5.6 顺子

五张或更多连续单牌。

规则：

- 最少 5 张。
- 不能包含 2。
- 不能包含大小王。

### 5.7 连对

三组或更多连续对子。

规则：

- 最少 3 对。
- 不能包含 2。
- 不能包含大小王。

### 5.8 飞机

两个或更多连续三张，不带牌。

规则：

- 最少 2 个三张。
- 不能包含 2。
- 不能包含大小王。

### 5.9 飞机带单

连续三张加同数量单牌。

示例：

```text
333444 + 5 6
```

两个三张必须带两个单牌。

### 5.10 飞机带对

连续三张加同数量对子。

示例：

```text
333444 + 55 66
```

两个三张必须带两个对子。

### 5.11 四带二单

四张相同点数加两张单牌。

```text
3333 + 4 5
```

MVP 允许该牌型。

### 5.12 四带二对

四张相同点数加两个对子。

```text
3333 + 44 55
```

MVP 允许该牌型。

### 5.13 炸弹

四张相同点数。

```text
S7 H7 D7 C7
```

### 5.14 火箭

大小王。

```text
BJ RJ
```

火箭是最大牌型。

## 6. 比较规则

### 6.1 相同牌型

非炸弹、非火箭牌型：

- 必须类型相同。
- 结构长度相同。
- 候选牌 primary rank 高于上一手。

示例：

- 单 4 压单 3。
- 对 6 压对 5。
- 4-8 顺子压 3-7 顺子。
- 4-9 顺子不能和 3-7 顺子比较，因为长度不同。

### 6.2 炸弹

- 炸弹压任意非炸弹、非火箭。
- 高点数炸弹压低点数炸弹。
- 炸弹不能压火箭。

### 6.3 火箭

- 火箭压所有牌。
- 没有牌能压火箭。

### 6.4 不同牌型

不同的非炸弹牌型不能比较。

## 7. 回合规则

- 地主首先出牌。
- 回合按座位顺序：0 -> 1 -> 2 -> 0。
- 主动出牌时必须出牌。
- 只有响应他人有效出牌时才能不出。
- 连续两家不出后，上一手出牌玩家获得新一轮主动权。

## 8. 超时规则

叫分超时：

- 默认不叫。
- 必须强制动作时选择最低合法叫分。

出牌超时：

- 能不出则自动不出。
- 不能不出时，由机器人策略选择最小合法出牌。

## 9. 倍数规则

MVP 倍数：

- 初始倍数为叫分，最低 1。
- 每个炸弹倍数翻倍。
- 火箭倍数翻倍。

后续可选：

- 春天。
- 反春。
- 不洗牌。
- 加倍房。

MVP 可暂不实现春天/反春，除非后续明确要求。

## 10. 结算

地主胜：

- 地主获得 `base_score * multiplier * 2`。
- 每个农民失去 `base_score * multiplier`。

农民胜：

- 地主失去 `base_score * multiplier * 2`。
- 每个农民获得 `base_score * multiplier`。

分数变化总和必须为 0。

## 11. 函数契约

推荐 Go 函数：

```go
func ParseCard(code string) (Card, error)
func NewDeck() []Card
func Shuffle(deck []Card, rng RNG) []Card
func Deal(deck []Card) (hands [3][]Card, bottom []Card, err error)
func Recognize(cards []Card) (CardGroup, error)
func CanBeat(candidate CardGroup, previous CardGroup) bool
func RemoveCards(hand []Card, cards []Card) ([]Card, error)
func ContainsCards(hand []Card, cards []Card) bool
func LegalResponses(hand []Card, previous *CardGroup) []CardGroup
```

## 12. 边界情况

必须处理：

- 选择牌中有重复牌。
- 牌不在手牌中。
- 空出牌。
- 非法牌型。
- 顺子包含 2。
- 顺子包含王。
- 飞机带牌歧义。
- 四带二不能误判为炸弹。
- 火箭必须且只能是大小王两张。

## 13. 规则验收标准

- 所有牌型可识别。
- 非法牌型被拒绝。
- 比较符合规则。
- 结算分数总和为 0。
- 测试覆盖边界情况。
